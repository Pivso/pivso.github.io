# pivso.github.io

The website of Tomáš Cerman, served by GitHub Pages at https://pivso.github.io/.

Privacy policies for each app are listed on the home page. Krmshee's lives in its own repo,
`Pivso/krmshee-privacy` (already in its Play listing, so it stays there); newer apps live here,
under `<app>/privacy/`, starting with Bro-tivator at `brotivator/privacy/`. Each page is the app
repo's `store_listing/privacy-policy.md` converted by hand; change both together.
